# MegaPack: Trailers & Cargo

Personal-use ETS2 mod that merges Jazzycat's trailer and cargo packs (Trailers & cargo, Military cargo,
Railway cargo) into one conflict-resolved set: company trailers, cargo jobs and AI traffic trailers, with
cargo pay balanced to follow [DriveDogs Economy](https://github.com/DevilDogTG/ETS2Mods.DriveDogs.Economy)'s
rules. This repo contains **configuration only**. Source content lives outside git.
See [ADR-0001](docs/adr/ADR-0001-one-megapack-requires-economy.md).

## Sources
| Pack (Jazzycat) | Version | Archives used |
|---|---|---|
| Trailers & cargo | 11.10.6 | part1-3 |
| Military cargo | 6.8.7 | base, eng, traffic add-on |
| Railway cargo | 4.6.7 | main |

Not used: the Overweight pack (older copies of files already in the main pack) and Military `rus`. Origin
links are in `sources.yaml`.

## Structure
- `megapack.yaml`: package identity, `source_root`, excludes, part size caps
- `sources.yaml`: every origin mod: author, version, origin URL, layer, overrides
- `lock/`: generated per-source path and hash lists (commit them; `git diff` shows upstream changes)
- `cargo/`: cargo pay following DriveDogs Economy ([ADR-0002](docs/adr/ADR-0002-cargo-pay-follows-economy.md)).
  `fixes.yaml` holds hand-reviewed fixes of Jazzycat data bugs; `edits.yaml` (generated: rates + fixes) is applied
  at build via `megapack.yaml` `base_edits`; `analysis.md`/`.tsv` and `rebalance.md` are the generated reports.
  `tools/cargo_rebalance.py` reads Economy's rules from the Economy repo (host root `@drivedogs_economy`)
- `cargo/icons.yaml` + `tools/cargo_icons.py`: freight-market icons. Jazzycat ships none and the game finds a cargo's
  icon only at `material/ui/cargo_icons/<cargo_id>.mat`, so the tool writes one alias `.mat` per cargo into
  `overrides/` pointing at the closest base-game icon (no DLC icons: a DLC the player lacks would leave it blank).
  `cargo/icons.md` lists every pick. Rerun after a source update or a change to `icons.yaml`
- `tools/fix_models.py`: fixes misnamed locators in Jazzycat models (flatbed4's body locator is named `hook` in the
  main pack, so its cargo had nowhere to attach) by renaming only that locator in the source model, written into
  `overrides/`. `--check` verifies the written models. Rerun after a source update
- `overrides/`: files laid over the merged sources at build (the generated cargo icons and fixed models)
- `resolutions.yaml`: the source copy each `overrides/` file replacing a shipped file was made from, so `megapack check`
  warns when upstream changes it
- `src/manifest.sii`, `src/description.txt`: templates for each output part's manifest
- `src/cover.jpg`: mod manager icon (276x162), generated by `tools/generate_cover.py` from `logo.png` and the
  version in `megapack.yaml` (needs Pillow + PyYAML). Rerun after a version bump.
- `output/local/`: built `.scs` parts (gitignored)

## Building
Uses the `scs-mod-developer` profile's `megapack` skill:
1. `extract-reference` for each source not yet extracted.
2. `megapack lock` refreshes `lock/` and reports collisions.
3. `python tools/cargo_rebalance.py analyze` (report) and `generate` (writes `cargo/edits.yaml`); rerun after
   a source update, a change to `cargo/fixes.yaml` or a rule change in DriveDogs Economy.
4. `python tools/cargo_icons.py` refreshes the cargo icon aliases in `overrides/`; `python tools/fix_models.py`
   the fixed models.
5. `megapack check` reports stale locks, unresolved collisions and edits that no longer apply.
6. `megapack build` writes `output/local/<name>_partN_v<version>.scs` (`package.versioned_filenames`, the
   DriveDogs naming convention; one archive since 1.1.0, ~110k entries, loads clean in game).
   Needs the base game of `base_game.version` extracted (`extract-reference`, category `base`):
   `exclude_unknown_companies` drops cargo links to companies it does not have (map-mod companies).

## Installing
Copy the `.scs` from `output/local/` into the ETS2 `mod` folder and enable it.
Each release has a new file name (`_v<version>`), so disable and remove the previous version (1.0.2 and older
came as several parts: remove all of them). Load order does not matter against DriveDogs Economy and the AI
Traffic megapack (they share no paths, or only byte-identical ones).

Requires DriveDogs Economy. Built without map-mod support: Jazzycat cargo appears only at companies of the base
game and its DLCs, not at ProMods/RusMap companies. Do not load the original Jazzycat trailer/cargo packs (including the Overweight
pack and the traffic add-ons): they are built in. Built for ETS2 1.61.
